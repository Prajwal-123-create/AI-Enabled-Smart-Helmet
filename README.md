# AI-Enabled Smart Helmet

## Overview
A proposed wearable safety system designed to improve
industrial worker safety through gas detection,
fall monitoring, and real-time alerts.

## Objectives
- Detect smoke and certain combustible gases.
- Monitor worker movement and possible falls.
- Process sensor readings using an ESP32.
- Explore wireless alerts through a monitoring application.

## Hardware Components
- ESP32
- MQ-2 Gas Sensor
- MPU6050 Accelerometer and Gyroscope
- Power Supply

## Technology
- Embedded C/C++
- Arduino IDE
- Wi-Fi Communication

## Development Status
Prototype under development.
